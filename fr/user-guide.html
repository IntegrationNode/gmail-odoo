Guide d'utilisation

Tout ce que vous devez savoir pour tirer le meilleur parti de l'intégration Odoo pour Gmail

Démarrage rapide (2 minutes, sans clé API)
  1. Installez l'extension et ouvrez Gmail.
  2. Connectez-vous à votre Odoo dans le même navigateur Chrome — l'extension utilise votre session active.
  3. Saisissez votre URL Odoo (ex. https://votreentreprise.odoo.com — HTTPS, sans barre oblique finale) et cliquez sur Se connecter à Odoo. Sur odoo.com, vous pouvez aussi cliquer sur Détecter Odoo automatiquement pour le trouver dans un onglet ouvert.
Ouvrez n'importe quel email et votre contact Odoo apparaît dans la barre latérale. C'est tout — pas de clé API, pas de code.

download Installation

Prérequis

  • Navigateur Chrome: Version 88 ou supérieure
  • Instance Odoo: Version 14.0 ou supérieure (on-premise, Odoo.sh ou Odoo Online plan Custom)

Installation étape par étape

  1. Visitez le Chrome Web Store
    Accédez à Intégration Odoo pour Gmail ou recherchez "Odoo Integration for Gmail" dans le Chrome Web Store.
  2. Ajouter à Chrome
    Cliquez sur le bouton "Ajouter à Chrome" et examinez les autorisations demandées.
  3. Vérifier l'installation
    Vous verrez un message de confirmation et l'icône de l'extension apparaîtra dans votre barre d'outils Chrome.
  4. Épingler l'extension (Recommandé)
    Cliquez sur l'icône puzzle dans la barre d'outils Chrome, trouvez "Odoo Integration for Gmail" et cliquez sur l'icône d'épingle.
Note concernant la "Navigation sécurisée renforcée" : Si vous voyez un message indiquant "Cette extension n'est pas approuvée par la navigation sécurisée renforcée", c'est normal pour les extensions nouvellement publiées. L'extension a été examinée et approuvée par le Chrome Web Store.

settings Configuration

Première configuration

  1. Ouvrir Gmail
    Accédez à mail.google.com et ouvrez n'importe quel email pour voir la barre latérale.
  2. Connectez-vous à Odoo
    Assurez-vous d'être connecté à votre instance Odoo dans le même navigateur — l'extension se connecte via votre session active.
  3. Entrer votre URL Odoo
    Entrez l'URL de votre instance Odoo (ex: https://votreentreprise.odoo.com). Utilisez HTTPS et n'incluez pas de barre oblique finale.
  4. Connecter
    Cliquez sur Se connecter à Odoo et l'extension vérifie votre session active. Une clé API est facultative : l'enregistrement automatique en a besoin, et elle sert aussi de secours si votre session expire.
info Ajouter une clé API est facultatif. Si vous en ajoutez une, les étapes de création varient selon les versions d'Odoo. Consultez le guide détaillé pour votre version →

Mise à jour de la configuration

Pour connecter l'extension à un autre Odoo :

  1. Cliquez sur le bouton menu (trois points verticaux ⋮) dans l'en-tête du panneau et choisissez Paramètres
  2. Ouvrez Connexion et cliquez sur Changer d'Odoo
  3. Saisissez la nouvelle adresse et connectez-vous

Pour ajouter ou changer votre clé API plus tard, ouvrez Paramètres → Connexion. Déconnexion s'y trouve aussi, en bas de la section.

Choisir quand le panneau s'ouvre

Par défaut, le panneau Odoo s'ouvre tout seul à chaque email ouvert. Pour ne l'ouvrir qu'au besoin, désactivez « Ouvrir le panneau à l'ouverture d'un e-mail » dans Paramètres → Général. Le panneau reste alors fermé jusqu'à ce que vous cliquiez sur l'icône Odoo dans la barre latérale droite de Gmail. Le changement s'applique immédiatement, sans recharger Gmail.

credit_card Gestion de l'abonnement

Comment s'abonner à PLUS

  1. Cliquez sur « Essayez Plus 14 jours » dans le menu du panneau (trois points dans l'en-tête) ou dans Paramètres → Formule
  2. Complétez le processus de paiement sur Polar
  3. Recevez votre clé de licence par email

Activer votre Licence

Entrez votre clé de licence de l'une de ces façons :

  • Une fenêtre apparaîtra juste après le paiement - entrez votre licence ici
  • Allez dans Paramètres → Formule et cliquez sur « J'ai déjà une licence »
  • Dans la fenêtre Plus qui s'ouvre depuis « Essayez Plus 14 jours », cliquez sur « J'ai déjà une licence »
Informations sur la Licence : Votre licence fonctionne sur jusqu'à 3 instances (différents ordinateurs ou navigateurs). Elle doit être utilisée avec le même compte Gmail que celui utilisé pour l'achat. Pour libérer un ordinateur, cliquez sur « Désactiver ici » dans Paramètres → Formule.
Essai Gratuit : PLUS inclut un essai gratuit de 14 jours. L'essai demande une carte, mais rien n'est facturé avant sa fin. Annulez à tout moment avant pour éviter les frais.
Tarification régionale : Nous offrons des prix justes. Les prix sont automatiquement ajustés lors du paiement via une réduction.

Comment annuler votre abonnement

Vous pouvez annuler votre abonnement PLUS à tout moment :

  1. Dans Paramètres → Formule, cliquez sur « Gérer l'abonnement » pour ouvrir le portail client Polar (le lien figure aussi dans votre email d'achat)
  2. Connectez-vous avec l'email utilisé pour votre abonnement
  3. Cliquez sur "Annuler l'abonnement" dans les détails de votre abonnement

Vos fonctionnalités PLUS resteront actives jusqu'à la fin de votre période de facturation en cours.

mail Enregistrement d'emails

Comment enregistrer un email

  1. Ouvrez l'email que vous souhaitez enregistrer
  2. Consultez le contact dans la barre latérale
  3. Pour l'enregistrer sur le contact, cliquez sur Enregistrer l'e-mail, sous son nom
  4. Pour l'enregistrer sur une opportunité, une tâche, un ticket, un devis ou une commande, cliquez sur l'icône enveloppe de sa ligne
  5. Une notification confirme où il a été enregistré, avec Annuler si vous vous êtes trompé d'enregistrement. L'enveloppe affiche ensuite une coche

Ce qui est enregistré

  • Sujet de l'email (dans l'en-tête)
  • Corps de l'email (formaté en HTML)
  • Informations expéditeur/destinataire
  • Date et heure
  • Toutes les pièces jointes (fichiers, images, PDFs)
  • Pied de page « Logged from Gmail in 1-click »
Enregistré comme Note Interne : Les emails sont enregistrés comme notes internes dans le chatter d'Odoo. Cela signifie que seuls les utilisateurs internes (employés) peuvent les voir. Les utilisateurs du portail (clients) NE verront PAS les emails enregistrés. Les notifications ne sont envoyées qu'aux abonnés internes de l'enregistrement.

Détection des doublons

L'extension dispose de deux niveaux de détection des doublons :

  1. Indicateur visuel (0-6 heures): Vous aide à identifier d'un coup d'œil quels enregistrements contiennent déjà cet email
  2. Validation côté serveur (toujours): Odoo empêche les doublons même si l'indicateur visuel a expiré
Important : Même sans l'indicateur visuel, vous ne pouvez pas créer accidentellement de doublons. Le serveur Odoo valide chaque demande d'enregistrement et rejette les doublons.

more_vert Actions sur un enregistrement

Chaque ligne d'opportunité, de tâche, de ticket, de devis, de commande et de contact associé dispose de son propre menu d'actions. Placez le pointeur sur la ligne et cliquez sur le bouton ⋮ qui apparaît sur son bord droit. Le menu commence toujours par Ouvrir dans Odoo et Copier le lien.

Copier un lien vers l'enregistrement

Copie un lien direct vers cet enregistrement dans Odoo, prêt à être collé dans une réponse ou une conversation. Il pointe vers l'enregistrement que la ligne ouvre lorsque vous cliquez dessus.

Activer ou désactiver l'enregistrement automatique Plus

Activer l'enregistrement auto associe le fil actuel à cet enregistrement ; Désactiver l'enregistrement auto le dissocie. L'option n'apparaît que si l'enregistrement automatique est disponible pour ce fil. En pause, elle reste visible mais désactivée, afin de distinguer une association en pause d'une association jamais créée.

Fermer le menu

Les options qui ne s'appliquent pas à une ligne sont omises plutôt que grisées : le menu n'affiche que ce que vous pouvez réellement faire. Cliquez en dehors du menu, ou appuyez sur Échap, pour le fermer sans rien déclencher.

sync Enregistrement automatique Plus

L'enregistrement automatique associe un fil Gmail à un ou plusieurs enregistrements Odoo : chaque nouvel email du fil est enregistré tout seul dans le chatter de l'enregistrement, sans cliquer sur l'icône enveloppe à chaque réponse.

Bêta privée : L'enregistrement automatique est actuellement en bêta privée. Il sera bientôt disponible pour tous les abonnés PLUS. Pour l'essayer plus tôt, écrivez-nous depuis Envoyer un commentaire, dans le menu du panneau.

Prérequis

  • Formule PLUS (et accès à la bêta pendant la bêta privée)
  • Une clé API, ajoutée dans Paramètres → Connexion. L'enregistrement automatique travaille en arrière-plan, même Gmail fermé : il ne peut donc pas utiliser la session de votre navigateur
  • L'interrupteur « Activer l'enregistrement automatique » allumé, dans Paramètres → Enregistrement des e-mails
  • Gmail connecté : cliquez sur Connecter Gmail dans Paramètres → Enregistrement des e-mails

Activer l'enregistrement automatique sur un fil

  1. Ouvrez le fil dans Gmail et affichez le contact dans la barre latérale
  2. Trouvez l'enregistrement à suivre (une opportunité, une tâche, un ticket, une commande ou le contact lui-même)
  3. Pour un enregistrement des listes, ouvrez son menu ⋮ et choisissez Activer l'enregistrement auto. Pour le contact lui-même, utilisez le bouton d'enregistrement automatique à côté d'Enregistrer l'e-mail. Une notification le confirme, et une icône de synchronisation reste à côté du nom de l'enregistrement tant que l'enregistrement automatique est actif
  4. Dès lors, chaque nouvel email de ce fil est enregistré automatiquement dans le chatter de cet enregistrement
Seulement les emails à venir : L'enregistrement automatique ne regarde que vers l'avant. Les emails déjà présents dans le fil avant l'activation ne sont PAS enregistrés rétroactivement. Pour les enregistrer, utilisez le bouton enveloppe comme d'habitude.

Ce qui est enregistré

Chaque nouvel email est ajouté comme note interne dans le chatter de l'enregistrement, avec :

  • Un en-tête à la manière de Gmail (De, À, Date, Objet)
  • Le corps de l'email, sans l'historique cité
  • La date d'origine de l'email (et non l'heure de son traitement)
  • Les partenaires liés — les destinataires sont retrouvés dans Odoo par leur adresse et associés au message
  • Un pied de page « Auto-logged from Gmail » avec un lien vers l'extension
Enregistré comme note interne : Les emails enregistrés automatiquement sont des notes internes (mt_note), pas des messages publics. Seuls les utilisateurs internes d'Odoo les voient — pas les utilisateurs du portail (clients).

Associer un fil à plusieurs enregistrements

Vous pouvez activer l'enregistrement automatique d'un même fil sur plusieurs enregistrements (par exemple, une opportunité et une tâche liées à la même conversation) :

  • 1 fil → 1 enregistrement : le cas habituel.
  • 1 fil → plusieurs enregistrements : chaque nouvel email est enregistré sur chaque enregistrement lié, l'un après l'autre.
  • Un même enregistrement ne peut pas être associé deux fois depuis le même fil — les doublons sont refusés.

Gérer l'enregistrement automatique

Depuis la barre latérale (par fil)

Quand le fil ouvert a l'enregistrement automatique actif sur au moins un enregistrement, une section « Enregistrement automatique », avec le nombre d'enregistrements liés, apparaît en haut de la barre latérale :

  • Cliquez sur la section pour la déplier et voir tous les enregistrements associés au fil actuel
  • Cliquez sur le nom d'un enregistrement pour l'ouvrir dans Odoo
  • Cliquez sur le bouton ✕ pour désactiver l'enregistrement automatique sur cet enregistrement

Depuis Paramètres (tous les fils)

Ouvrez Paramètres → Enregistrement des e-mails pour gérer tous les fils avec enregistrement automatique :

  • Activez ou désactivez l'enregistrement automatique sur tous les fils avec un seul interrupteur
  • Connectez Gmail, ou reconnectez-le
  • Consultez les fils avec enregistrement automatique, leur nombre et l'heure de la dernière vérification
  • Désactivez-les tous d'un coup avec « Tout désactiver »

Limites et cas particuliers

  • Non rétroactif: Seuls les emails arrivés après l'activation sont enregistrés. Les emails existants s'enregistrent à la main.
  • Nettoyage automatique après 90 jours: Une association sans nouvel email pendant 90 jours est supprimée automatiquement. Réactivez-la pour reprendre.
  • Enregistrement supprimé dans Odoo: Si l'enregistrement lié est supprimé dans Odoo, l'association disparaît automatiquement la prochaine fois que l'extension essaie d'y enregistrer un email.
  • Gmail déconnecté: Si la connexion à Gmail expire ou est révoquée, l'enregistrement automatique s'arrête sur tous les fils jusqu'à ce que vous la rétablissiez depuis Paramètres → Enregistrement des e-mails.

groups Utiliser les contacts associés Plus

La section Contacts associés du panneau latéral liste les collègues de la même entreprise que l'expéditeur de l'e-mail. Depuis cette section, ou depuis le menu ⋮ de chaque contact, vous pouvez effectuer des actions rapides sans quitter Gmail.

Ouvrir un contact dans Odoo

Cliquez n'importe où sur la carte du contact — l'avatar, le nom ou la fonction — pour ouvrir sa fiche dans Odoo dans un nouvel onglet.

Envoyer un nouvel e-mail à un contact

Cliquez sur l'icône d'e-mail à côté de l'adresse du contact. Si aucun brouillon n'est ouvert, Gmail ouvre une nouvelle fenêtre de rédaction avec cette adresse pré-remplie dans le champ À.

Ajouter un contact à un e-mail en cours de rédaction

Si une fenêtre de rédaction Gmail est déjà ouverte au moment où vous cliquez sur l'icône d'e-mail, le contact est ajouté comme destinataire de ce brouillon au lieu d'en ouvrir un nouveau. L'extension choisit où : si le champ À est vide, le contact y est placé ; s'il contient déjà quelqu'un, le contact est ajouté en CC et la fenêtre de rédaction est minimisée pour vous permettre de continuer à cliquer sur d'autres contacts et construire la liste des destinataires.

Copier l'e-mail ou le téléphone d'un contact

Cliquez sur le texte de l'e-mail ou du téléphone — pas sur l'icône à côté — pour le copier dans votre presse-papiers. Une petite notification confirme la copie.

Appeler un contact

Cliquez sur l'icône de téléphone pour démarrer un appel. L'action est transmise à l'application que votre système associe aux numéros de téléphone — le composeur de votre mobile, FaceTime, Skype, Microsoft Teams, etc. Si aucune application n'est configurée, le clic ne fait rien.

history Parcourir les messages dans Odoo Plus

La section Messages dans Odoo affiche les derniers e-mails et notes Odoo où apparaît le contact — sur sa fiche ou sur une opportunité, une tâche, une commande… —, pour que vous voyiez ce qui a été dit sans quitter Gmail.

Voir exactement quand un message a été envoyé

Chaque entrée affiche une date relative comme « il y a 5 jours ». Survolez la date pour voir le jour et l'heure exacts, formatés selon la langue de votre navigateur.

Aller directement à un message dans Odoo

Cliquez sur une entrée de Messages dans Odoo pour ouvrir la fiche Odoo associée dans un nouvel onglet. Sur Odoo 18 et versions ultérieures, le clic va plus loin : Odoo défile jusqu'à ce message précis et le met en surbrillance. Sur Odoo 16 et 17, la fiche s'ouvre normalement — le clic vous évite la navigation, mais il faudra défiler pour trouver le message.

handshake Gestion des opportunités

Visualisation des opportunités

Quels enregistrements sont affichés :

  • Opportunités liées au contact (par partner_id)
  • Triées par date de création (plus récentes en premier)

Créer des prospects à partir d'emails

Convertissez une conversation email en opportunité Odoo en un clic :

  1. Ouvrez l'email que vous souhaitez convertir en prospect
  2. Consultez le contact dans la barre latérale
  3. Faites défiler jusqu'à la section Opportunités
  4. Cliquez sur le bouton "Créer"

Ce qui se passe automatiquement :

  • Le prospect est créé avec le sujet de l'email comme nom
  • Le contenu de l'email est ajouté en description
  • Le contact de la barre latérale est lié
  • Le prospect s'ouvre dans Odoo dans un nouvel onglet pour modification
  • Pendant la création, le bouton affiche un état de traitement, et des clics répétés ne créent pas de doublons
Important : L'email n'est PAS enregistré automatiquement. Pour associer l'email au nouveau prospect, retournez dans Gmail et cliquez sur l'icône enveloppe à côté de l'opportunité.

request_quote Devis en attente Plus

La section Devis répertorie les devis du contact encore ouverts — brouillons et devis déjà envoyés — pour voir ce qui attend une décision sans quitter Gmail.

Prérequis

  • Formule PLUS. Dans la formule gratuite, la section reste visible, verrouillée, avec un lien pour passer à PLUS.
  • Le module Ventes installé dans Odoo et le droit de créer des devis. Si votre utilisateur dispose des Ventes en lecture seule, la section n'apparaît pas.

Comment la liste est organisée

  • Non envoyé: devis encore en brouillon : c'est à vous de jouer.
  • En attente du client: déjà envoyés : la balle est dans le camp du client.

Chaque ligne affiche le montant et un indicateur de temps : depuis combien de temps le devis attend (« Créé il y a 5 jours ») ou quand il expire (« Expire demain », « Expiré »). Les devis expirés, ou qui expirent sous une semaine, sont mis en évidence.

Ce que vous pouvez faire

  • Cliquez sur une ligne pour ouvrir le devis dans Odoo.
  • Cliquez sur l'icône enveloppe pour enregistrer l'email courant dans le chatter de ce devis.
  • Cliquez sur Créer pour démarrer un nouveau devis pour le contact et le finaliser dans Odoo.
  • Ouvrez le menu ⋮ de la ligne pour ouvrir le devis dans Odoo ou copier un lien vers lui, et utilisez la recherche quand la liste s'allonge.

Lorsque vous confirmez un devis, il quitte cette liste et rejoint les Commandes confirmées, où vous pouvez continuer à enregistrer la correspondance qui suit.

Vous ne travaillez pas avec des devis ? Masquez la section depuis Paramètres → Panneau.

receipt_long Commandes confirmées Plus

La section Commandes affiche les commandes déjà confirmées du contact, afin que la conversation qui suit la vente — livraisons, modifications de quantités, facturation, incidents — soit enregistrée sur la commande elle-même.

Elle comble un vrai manque : dès qu'un devis est confirmé, il quitte la section Devis et aucune autre section ne le reprenait jusqu'ici. À partir de là, l'e-mail ne pouvait plus être enregistré que sur le contact, au moment précis où la correspondance est la plus dense.

Prérequis

  • Formule PLUS. Avec la formule gratuite, la section reste visible, nommée, avec un lien pour passer à PLUS — et elle n'envoie aucune requête à Odoo.
  • Le module Ventes installé dans Odoo et le droit de lecture sur les commandes. La lecture seule suffit : contrairement aux Devis, cette section ne crée jamais de document, elle convient donc aussi aux profils qui suivent les commandes sans les modifier.

Ce que la liste affiche

  • Uniquement les commandes en cours : confirmées et actives, y compris verrouillées. Les commandes annulées et les devis non encore confirmés en sont exclus.
  • Chaque ligne affiche la référence de la commande, son montant total avec la devise et sa date. Les plus récentes d'abord.
  • Aucun filtre d'ancienneté : une commande compte tant qu'elle est en cours, quelle que soit sa date. Lorsqu'il y a plus de commandes que la liste n'en affiche, l'en-tête indique combien sont montrées sur le total.
  • Dans la vue société, la liste inclut également les commandes des contacts rattachés à cette société.

Ce que vous pouvez faire

  • Cliquez sur une ligne pour ouvrir la commande dans Odoo.
  • Cliquez sur l'icône enveloppe pour enregistrer l'e-mail ouvert dans la conversation de cette commande. Une commande où l'e-mail est déjà enregistré est signalée comme telle et n'accepte pas de doublon.
  • Ouvrez le menu ⋮ de la ligne pour copier un lien vers la commande ou activer l'enregistrement automatique, afin que les e-mails suivants du fil soient enregistrés sur la commande sans intervention.
  • Utilisez la recherche pour retrouver une commande par sa référence. C'est le moyen d'atteindre une commande ancienne qui ne figure pas parmi les plus récentes.

La section ne crée pas de commandes : une commande naît de la confirmation d'un devis dans Odoo, pas de la lecture d'un e-mail.

Vous ne suivez pas les commandes depuis votre messagerie ? Masquez la section depuis Paramètres → Panneau.

Pendant la création, le bouton affiche un état de traitement, et des clics répétés ne créent pas de doublons.

account_balance Informations financières Plus

La section financière résume l'état du compte avec le contact — ce qu'il vous doit, ce que vous lui devez, ce qui reste à facturer — sans ouvrir la comptabilité dans Odoo.

Les montants sont ceux de la société, pas de la personne : lorsque le contact est rattaché à une société mère dans Odoo, la section affiche les totaux de cette société.

Prérequis

  • Formule PLUS. Avec la formule gratuite, la section n'apparaît pas.
  • Le module Facturation ou Comptabilité installé dans Odoo et le droit de lecture sur les factures. Sans ce droit, la section reste masquée au lieu d'afficher une erreur.

Ce qu'elle affiche

  • En retard: le montant échu et le nombre de factures concernées. Sur Enterprise avec le module de relances activé, la date de la prochaine relance et le niveau de relance s'affichent également. Le bloc informe : aucune action n'y est rattachée.
  • Encours clients: ce que le contact vous doit.
  • Encours fournisseurs: ce que vous devez au contact.
  • Limite de crédit: la limite définie dans Odoo, lorsqu'il y en a une.
  • À facturer: déjà livré, pas encore facturé.
  • Total facturé: le total historique de cette société.
  • DSO (jours): le nombre de jours moyen avant paiement des factures.

Un montant à zéro est omis plutôt qu'affiché à zéro : la section ne liste que ce qui a réellement une valeur. Quand rien n'a de valeur et qu'il n'y a aucun retard, la section entière ne s'affiche pas — c'est le cas normal d'un contact sans historique de facturation.

Vous n'avez pas besoin des chiffres dans votre messagerie ? Masquez la section depuis Paramètres → Panneau.

notifications Notifications Odoo Plus

Organisez les emails de notification Odoo directement dans votre boîte de réception Gmail. L'extension reconnaît les notifications d'Odoo et leur ajoute une étiquette, pour voir instantanément à quel module elles appartiennent et si vous avez été mentionné.

Prérequis : Activer les Notifications par Email dans Odoo

Pour que cette fonctionnalité fonctionne, votre utilisateur Odoo doit être configuré pour recevoir les notifications par email (et non dans la boîte Odoo) :

  1. Dans Odoo, allez dans votre Profil (menu en haut à droite > Mon Profil)
  2. Dans Préférences, trouvez le paramètre "Notification"
  3. Sélectionnez "Gérer par e-mails" (au lieu de "Gérer dans Odoo")
Cela garantit qu'Odoo envoie les emails de notification à votre Gmail, où l'extension peut les identifier et les organiser.

Configuration

  1. Trouvez votre email de notification dans Odoo
    Vérifiez un email de notification Odoo récent dans Gmail et regardez l'adresse de l'expéditeur (ex : notifications@votreentreprise.com). Vous pouvez aussi demander à votre administrateur Odoo l'email de notification sortant.
  2. Ouvrez les Paramètres de l'extension
    Dans l'en-tête du panneau, cliquez sur le bouton menu (trois points verticaux) et choisissez Paramètres.
  3. Entrez l'email de notification
    Ouvrez la section Notifications Odoo, collez l'adresse dans Expéditeur des notifications et cliquez sur Enregistrer. L'extension commence aussitôt à reconnaître les notifications.
Astuce : Si vous ne savez pas quel email Odoo utilise pour les notifications, vérifiez un email de notification récent dans Gmail et regardez l'adresse de l'expéditeur.

Étiquettes de module

À côté de chaque notification de votre boîte, une étiquette indique le module Odoo qui l'a envoyée, chaque module avec sa couleur :

  • Opportunité (CRM)
  • Tâche (Projet)
  • Ticket (Assistance)
  • Facture (Facturation)
  • Et plus : Commande, Achat, Congé, Événement, Mailing…

Étiquette de mention

Quand quelqu'un vous mentionne dans un enregistrement Odoo (avec @ ou par nom), la notification porte l'étiquette Mention :

  • Étiquette Mention en rouge: Vous avez une mention non lue — vous n'avez pas ouvert ce fil dans Gmail depuis la mention
  • Étiquette Mention en gris: Vous avez déjà vu cette mention — vous avez ouvert le fil dans Gmail après avoir été mentionné
Comment ça marche : La détection des mentions est basée sur les messages stockés dans l'enregistrement Odoo, pas sur l'email lui-même. L'extension vérifie le chatter de l'enregistrement pour les @mentions ou les références à votre nom. Cela signifie :
  • Si vous êtes récemment passé de "Gérer dans Odoo" à "Gérer par e-mails", d'anciens fils peuvent afficher l'étiquette Mention pour des mentions survenues avant que vous ne commenciez à recevoir des emails — même si la mention n'apparaît dans aucun email Gmail.
  • Le statut lu/non lu dépend de l'ouverture ou non du fil dans Gmail après la mention. Une fois le fil ouvert, l'étiquette devient grise.

Accès Rapide

Un raccourci « Notifications Odoo » apparaît dans la barre latérale gauche de Gmail, sous vos libellés. Cliquez dessus pour filtrer votre boîte et n'afficher que les notifications d'Odoo.

Note : Le raccourci n'apparaît qu'après avoir indiqué l'expéditeur des notifications dans Paramètres → Notifications Odoo.

Naviguer par module

Le raccourci « Notifications Odoo » se déploie en sous-entrées — Opportunités, Tâches, Tickets, Factures, etc. —, chacune avec son propre compteur de non lus, pour aller directement aux notifications d'un module.

Les notifications issues de modèles hors de ce catalogue sont regroupées sous une entrée générique « Odoo » plutôt que d'être écartées.

Seules apparaissent les catégories des modules dont vous recevez effectivement des notifications.

Personnalisation

Chaque élément peut être activé ou désactivé dans Paramètres → Notifications Odoo :

  • Étiquette du module — afficher ou masquer les étiquettes de module
  • Étiquette de mention — afficher ou masquer les étiquettes de mention
  • Raccourci dans la barre latérale de Gmail — afficher ou masquer « Notifications Odoo » dans la barre latérale de Gmail

business Support multi-sociétés Plus

Si votre utilisateur Odoo a accès à plusieurs sociétés, l'extension vous laisse choisir laquelle est active. La société active détermine quels enregistrements la barre latérale vous montre et dans quelle société chaque nouveau lead, tâche, ticket ou contact est créé.

Prérequis

  • Plan PLUS
  • Un utilisateur Odoo avec accès à deux sociétés ou plus (dans Odoo : Paramètres > Utilisateurs > Sociétés autorisées)

Le sélecteur de société

Quand vous avez accès à plus d'une société, une icône de bâtiment apparaît dans l'en-tête du panneau, à côté du bouton menu (⋮) :

  • Survolez l'icône pour voir le nom de la société active (« Operating in {société} »)
  • Cliquez sur l'icône pour ouvrir un menu avec toutes les sociétés auxquelles vous avez accès. La société active est mise en évidence
  • Choisissez une société. Le menu se ferme et la barre latérale se rafraîchit avec les données de la nouvelle société
  • Si vous n'avez accès qu'à une seule société, l'icône ne s'affiche pas
Persistance : Votre sélection est enregistrée par instance Odoo : en rouvrant Gmail, vous retrouvez la société dans laquelle vous travailliez. Se déconnecter efface la sélection enregistrée.

Ce que la société active affecte

Une fois une société choisie, chaque opération de la barre latérale y est limitée :

  • Enregistrements que vous voyez: Les opportunités, tâches, tickets et contacts listés dans la barre latérale sont filtrés à ceux visibles dans la société active
  • Enregistrements que vous créez: Les nouveaux leads, tâches, tickets et contacts créés depuis la barre latérale sont affectés à la société active
  • Emails enregistrés automatiquement: Les emails enregistrés par l'enregistrement automatique sont publiés dans la société propriétaire de l'enregistrement lié (voir « Enregistrement automatique entre sociétés » ci-dessous)

Recherche de contacts entre sociétés

Si vous ouvrez un email de quelqu'un qui n'est pas dans la société active mais existe ailleurs dans votre instance Odoo, la barre latérale vous le signale et vous propose des actions au lieu de vous laisser un état vide.

Le contact existe dans une autre société

La barre latérale montre le contact trouvé, la société où il se trouve, et deux actions :

  • Rendre visible pour toutes les sociétés: Supprime la restriction de société du contact pour que les utilisateurs de chaque société à laquelle vous avez accès puissent le voir. Demande confirmation avant d'enregistrer
  • Créer un nouveau dans cette société: Crée un contact distinct dans la société active, sans toucher à l'original

Seule la société mère existe dans une autre société

Le contact est absent, mais une société liée (trouvée par le domaine de l'email) existe dans une autre de vos sociétés. Deux actions :

  • Partager la société entre toutes les sociétés: Rend la société mère visible pour toutes les sociétés auxquelles vous avez accès, puis vous laisse créer le contact sous elle
  • Créer la société ici: Crée un enregistrement de société indépendant dans la société active et le contact sous lui
Important : Partager un contact ou une société entre toutes vos sociétés change sa visibilité pour tous les utilisateurs ayant accès à ces sociétés. L'extension demande confirmation avant d'enregistrer.

Enregistrement automatique entre sociétés

Quand vous activez l'enregistrement automatique sur un enregistrement, l'extension mémorise la société à laquelle il appartient. Les nouveaux emails de ce fil sont toujours enregistrés dans la bonne société, même si vous avez changé de société active dans la barre latérale entre-temps.

Comportement avec le plan GRATUIT

Si vous avez accès à plusieurs sociétés avec le plan GRATUIT, l'extension utilise votre société par défaut dans Odoo pour toutes les opérations. L'icône du sélecteur n'apparaît pas et la recherche entre sociétés n'est pas proposée. Passer à PLUS débloque les deux.

Limites connues

  • Non synchronisé avec le sélecteur Odoo du navigateur: L'extension garde sa propre société active et l'envoie avec chaque requête, tandis que le sélecteur de société d'Odoo utilise la session de votre navigateur. Les deux sont indépendants — changer de société dans votre onglet Odoo ne change pas la société active dans Gmail, et inversement.
  • Société par défaut modifiée dans Odoo: Si votre administrateur change votre société par défaut dans Odoo, l'extension continue d'utiliser la valeur en cache jusqu'à ce que vous vous déconnectiez et reconnectiez.
  • Une société à la fois: Le sélecteur est à choix unique : la barre latérale montre les enregistrements d'une société à la fois. Pour voir ceux d'une autre société, basculez vers elle.
  • Erreur d'accès après la création d'un enregistrement: Quand vous créez une opportunité, une tâche, un ticket ou un contact depuis la barre latérale (ou cliquez sur « Voir dans Odoo »), l'extension ouvre l'enregistrement dans un nouvel onglet. Odoo le charge sous la société actuellement active dans votre session Odoo du navigateur (la session par cookie — voir ci-dessus). Si cette société diffère de celle où l'enregistrement a été créé, Odoo peut afficher une erreur d'accès. Avec le plan GRATUIT, l'extension crée toujours les enregistrements dans votre société Odoo par défaut — pour les voir, basculez votre onglet Odoo vers cette même société. Avec le plan PLUS, gardez la même société sélectionnée dans le sélecteur de la barre latérale et dans votre onglet Odoo. Odoo 18 et versions ultérieures changent automatiquement votre société active à l'ouverture d'un enregistrement appartenant à une autre de vos sociétés autorisées ; le problème se voit donc surtout sur Odoo 17 et antérieurs.

help Dépannage

L'extension n'apparaît pas dans Gmail

  1. Vérifiez que l'extension est activée: Allez sur chrome://extensions/ et assurez-vous que le commutateur est sur ON
  2. Actualisez Gmail: Appuyez sur Ctrl+Shift+R (Windows/Linux) ou Cmd+Shift+R (Mac)
  3. Rechargez l'extension: Cliquez sur "Recharger" sur la carte de l'extension

Message "Contact non trouvé"

  • Email non présent dans Odoo: Cliquez sur « Enregistrer dans Odoo » pour l'ajouter
  • L'adresse est écrite autrement: Les majuscules ne sont pas en cause : une adresse enregistrée dans Odoo sous la forme John@Acme.com correspond bien à john@acme.com. Ce qui casse la correspondance, c'est une adresse réellement différente : un alias, un point en trop ou un autre domaine. Mettez à jour l'email dans Odoo, ou créez un nouveau contact.

Une section n'apparaît pas

Les sections ne s'affichent que si Odoo peut les fournir. Si Opportunités, Tâches, Tickets, Devis ou Informations financières manque, vérifiez dans cet ordre :

  1. Le module n'est pas installé: Opportunités requiert CRM ; Tâches, Projet ; Tickets, Assistance (Enterprise) ; Devis, Ventes ; et Informations financières, Comptabilité.
  2. Votre utilisateur Odoo n'a pas les droits: L'extension masque une section lorsque votre utilisateur ne peut pas créer ce type d'enregistrement : un accès en lecture seule ne suffit pas. Demandez le droit à votre administrateur Odoo.
  3. Vous l'avez désactivée: Vérifiez Paramètres → Panneau : une section masquée y reste masquée sur tous les emails.

La barre latérale est vide ou rien ne se charge après la connexion

C'est presque toujours la session de connexion, pas une clé API. Vérifiez, dans l'ordre :

  1. Êtes-vous connecté à Odoo dans le même navigateur ?
    Ouvrez votre URL Odoo dans un autre onglet — si une connexion vous est demandée, connectez-vous, puis rechargez Gmail. L'extension utilise cette session.
  2. L'URL est-elle exacte ?
    Utilisez https://, l'URL réelle de votre instance, et sans barre oblique finale. Auto-hébergé : utilisez votre domaine personnalisé.
  3. Ouvrez un véritable email, pas la liste de la boîte de réception
    La fiche contact ne se charge que dans un email ouvert. Rechargez ensuite Gmail (Cmd/Ctrl+Shift+R).

Toujours bloqué ? Répondez à votre email de bienvenue ou envoyez-nous une capture d'écran — nous répondons vite : odoointegrations.team@gmail.com

« Session expirée » ou reconnexion demandée

Votre session Odoo a expiré. Ouvrez simplement Odoo, reconnectez-vous, et l'extension se reconnecte — rien d'autre à gérer.

Une clé API facultative peut être ajoutée en secours pour que les fonctionnalités en arrière-plan continuent de fonctionner quand la session expire : Paramètres → Connexion.

Le popup de permissions n'apparaît pas (Odoo auto-hébergé)

Lors de la connexion à une instance Odoo auto-hébergée (URL personnalisée), Chrome nécessite des permissions supplémentaires. Si le popup de permissions n'apparaît pas :

  1. Permission requise: Les URLs Odoo personnalisées (autres que *.odoo.com) nécessitent une permission Chrome supplémentaire pour communiquer avec votre serveur
  2. D'autres extensions peuvent bloquer les popups: Les bloqueurs de publicités, extensions de confidentialité ou bloqueurs de popups peuvent empêcher l'affichage du dialogue de permissions Chrome
  3. Solution: Désactivez temporairement les autres extensions (notamment les bloqueurs de publicités) et réessayez de vous connecter. Réactivez-les après avoir accordé la permission
Note : Cette permission n'est requise qu'une seule fois par URL Odoo. Après l'avoir accordée, l'extension fonctionnera normalement avec votre instance auto-hébergée.

quiz Questions fréquentes

Général

Q : Quelles versions d'Odoo sont supportées ?

Odoo 14.0 et versions supérieures sont supportées. Compatible avec les installations on-premise (Community/Enterprise), Odoo.sh et Odoo Online (plan Custom uniquement, car les plans Standard et Free n'ont pas accès à l'API externe).

Q : Ça fonctionne avec d'autres navigateurs ?

Actuellement, l'extension ne supporte que Google Chrome. Le support d'autres navigateurs pourrait être ajouté à l'avenir.

Q : Ai-je besoin d'une clé API ?

Non. Seulement votre URL Odoo et une session Odoo active dans le même navigateur. Une clé API est facultative — uniquement pour l'enregistrement automatique (PLUS) ou comme solution de secours si votre session expire.

Q : Mes données sont-elles sécurisées ?

Oui. L'extension n'accède qu'aux emails que vous consultez activement et communique de manière sécurisée avec votre instance Odoo via HTTPS, en utilisant votre propre session Odoo. Si vous ajoutez une clé API facultative, elle est stockée dans le stockage sécurisé de Chrome.

Abonnement

Q : Quelle est la différence entre GRATUIT et PLUS ?

GRATUIT inclut la consultation des contacts, l'enregistrement d'emails, la création d'enregistrements et les 5 premiers enregistrements de chaque section. PLUS ajoute tous les enregistrements avec recherche et regroupement, les devis et commandes, Messages dans Odoo, les informations financières, les contacts associés, les notifications Odoo, plusieurs sociétés et la personnalisation.

Q : Puis-je annuler mon abonnement PLUS à tout moment ?

Oui, vous pouvez annuler à tout moment sans pénalité. Votre abonnement restera actif jusqu'à la fin de votre période de facturation.

Confidentialité

Q : L'extension lit-elle tous mes emails ?

Non, l'extension n'accède qu'aux emails que vous consultez activement. Elle ne scanne pas toute votre boîte mail et ne lit pas les emails en arrière-plan.

Q : Ma clé API est-elle stockée de manière sécurisée ?

Une clé API est facultative — la plupart des utilisateurs se connectent avec leur session Odoo et n'en créent jamais. Si vous en ajoutez une, elle est stockée dans le stockage sécurisé de Chrome (chrome.storage.sync), que Chrome chiffre avec les identifiants de votre compte utilisateur OS.

Q : Qu'envoie l'extension lorsqu'un problème survient ?

Le message d'erreur, une trace technique, la version de l'extension et un identifiant aléatoire d'installation ; jamais le contenu de vos e-mails, vos identifiants ni vos données Odoo. Ces rapports d'erreur sont envoyés même si les statistiques d'utilisation sont désactivées, car ils décrivent l'état de l'application et non ce que vous en faites. C'est ce qui permet de détecter et corriger un défaut sans que vous ayez à le signaler. Vous pouvez vous y opposer à tout moment en nous écrivant ; voir la politique de confidentialité.
