Politique de confidentialité

Dernière mise à jour: October 31, 2026

Aperçu

Intégration Odoo pour Gmail ("l'Extension") s'engage à protéger votre vie privée. Cette politique de confidentialité explique comment l'Extension collecte, utilise et protège vos informations.

Développeur : OdooIntegrations Team

Informations que nous collectons

Données accessibles depuis Gmail

L'Extension accède aux informations suivantes de Gmail. Sauf indication contraire, uniquement à partir de l'e-mail que vous ouvrez :

  • Adresses email expéditeur et destinataire : Utilisées pour rechercher les contacts correspondants dans votre instance Odoo
  • Sujet et corps de l'email : Utilisés lorsque vous choisissez de créer des opportunités, tâches ou tickets dans Odoo
  • Date et métadonnées de l'email : Utilisées pour enregistrer les emails dans les fiches Odoo
  • Votre adresse Gmail : Lue au chargement de Gmail, pour vérifier qu'une licence PLUS appartient à ce compte, et pour la renseigner lorsque vous vous abonnez
  • Notifications Odoo (PLUS) : Uniquement si vous configurez les notifications Odoo : l'Extension vérifie l'expéditeur des e-mails de vos listes Gmail et lit ceux que votre Odoo vous envoie, même si vous ne les ouvrez pas, afin de les étiqueter par module
  • Pièces jointes : Téléversées dans votre Odoo lorsque vous enregistrez un e-mail ou créez une fiche à partir de celui-ci

Données accessibles depuis Odoo

L'Extension récupère les informations suivantes de votre instance Odoo :

  • Informations de contact (noms, emails, téléphones, entreprises)
  • Opportunités CRM associées aux contacts
  • Tâches projet associées aux contacts
  • Tickets helpdesk associés aux contacts
  • Informations entreprise et contacts associés
  • Devis, commandes clients, chiffres financiers et les messages dans lesquels le contact apparaît

Données consultées pour l'enregistrement automatique (facultatif)

L'enregistrement automatique est une fonctionnalité à activer volontairement. L'Extension n'accède à ces données qu'après que vous avez accordé l'accès à Gmail dans Paramètres > Enregistrement des e-mails (« Connecter Gmail ») et lié explicitement un fil à une fiche Odoo. Une fois un fil lié, l'Extension utilise l'API Gmail de Google pour :

  • Vérifier périodiquement les identifiants des nouveaux messages de votre compte pour trouver ceux des fils que vous avez liés (uniquement tant qu'au moins un fil est lié)
  • Lire l'objet, l'expéditeur, les destinataires, la date et le corps des nouveaux messages de ces fils
  • Les publier comme notes internes dans les fiches Odoo que vous avez liées

Scope: L'Extension ne demande que le scope OAuth gmail.readonly. Elle ne peut pas envoyer, modifier, archiver ni supprimer d'e-mails. L'enregistrement automatique s'arrête lorsque vous le désactivez pour un fil ou pour tous, ou que vous supprimez l'Extension. Les jetons peuvent également être révoqués à tout moment depuis les autorisations de votre compte Google.

Données de configuration

L'Extension stocke votre configuration dans le stockage de Chrome, dans votre navigateur :

  • URL de l'instance Odoo
  • Nom de la base de données
  • Identifiants d'authentification
  • Préférences utilisateur (paramètres des sections visibles)
  • Jetons OAuth de Gmail (uniquement si vous connectez Gmail pour l'enregistrement automatique) — nécessaires pour accéder à l'API Gmail en votre nom ; ils restent jusqu'à ce que vous supprimiez l'Extension ou révoquiez l'accès depuis votre compte Google
  • Liens de l'enregistrement automatique (liens entre fils et fiches, et identifiants des messages déjà enregistrés) — stockés dans votre navigateur tant que chaque lien existe
  • Société active sélectionnée et liste des sociétés auxquelles vous avez accès (instances multi-sociétés) — mises en cache localement pour mémoriser dans quelle société vous travaillez

Onglets Odoo ouverts

Lorsque vous cliquez sur « Détecter Odoo automatiquement », l'extension lit les adresses des onglets odoo.com ouverts dans ce navigateur, uniquement pour vous proposer votre instance. Elle ne lit pas leur contenu, et les adresses ne sont ni stockées ni envoyées.

Comment nous utilisons vos informations

L'Extension utilise vos informations uniquement aux fins suivantes :

  • Afficher les informations de contact : Montrer les détails des contacts Odoo pertinents dans la barre latérale de Gmail
  • Créer des enregistrements Odoo : Lorsque vous cliquez sur les boutons "Créer", le contenu de l'email est envoyé à votre instance Odoo pour créer des opportunités, tâches ou tickets
  • Enregistrer les emails : Lorsque vous cliquez sur les boutons "Enregistrer l'email", le contenu est sauvegardé dans le chatter de votre instance Odoo
  • Rechercher et filtrer : Rechercher parmi les opportunités, tâches et tickets associés aux contacts
  • Mise en cache : Mettre temporairement en cache les réponses API Odoo localement pour améliorer les performances
  • Enregistrement automatique : Lorsque vous activez l'enregistrement automatique pour une fiche, l'Extension consulte votre compte Gmail en arrière-plan pour détecter les nouveaux e-mails du fil lié et les publie comme notes internes dans votre instance Odoo
  • Notifications Odoo (PLUS) : Étiqueter par module les e-mails que votre Odoo vous envoie et indiquer où vous avez été mentionné
  • Statistiques d'utilisation et rapports d'erreur : Comprendre comment l'Extension est utilisée et corriger les défauts (voir Analytiques)
  • Abonnement et prix : Gérer votre abonnement PLUS, vérifier que la licence appartient à votre compte Gmail et vous montrer le prix pour votre pays (voir Services tiers)
  • Détection automatique d'Odoo : Lorsque vous cliquez sur « Détecter Odoo automatiquement », vous proposer votre instance à partir de vos onglets odoo.com ouverts

Stockage et sécurité des données

Stockage : La configuration et le cache sont stockés dans le stockage de Chrome, dans votre navigateur. Si vous utilisez la synchronisation Chrome, Chrome copie l'adresse de votre Odoo, votre clé API et vos préférences dans votre compte Google et sur vos autres appareils.

Transmission des données : L'Extension communique directement avec VOTRE instance Odoo via HTTPS. Vos identifiants Odoo ne sont jamais envoyés au développeur de l'extension.

Gestion du cache : Les données en cache cessent d'être utilisées au bout de quelques minutes et sont supprimées lorsque vous cliquez sur le bouton Actualiser ou que vous vous connectez à un autre Odoo. Supprimer l'Extension les efface de ce navigateur.

Services tiers

Polar (Traitement des paiements)

L'Extension utilise Polar (https://polar.sh/) pour la gestion des abonnements et le traitement des paiements. Lorsque vous souscrivez au plan PLUS, Polar collecte :

  • Votre adresse email pour la gestion du compte et les reçus
  • Informations de paiement (traitées de manière sécurisée par Stripe, non stockées par l'Extension)
  • Statut d'abonnement et informations de facturation
  • L'identifiant d'installation, lorsque vous activez une licence, pour distinguer vos appareils

Politique de Confidentialité de Polar : https://polar.sh/legal/privacy

Important : Les données de paiement sont entièrement gérées par Polar et Stripe. L'Extension ne reçoit ni ne stocke jamais vos informations de carte bancaire.

Prix par pays

Pour vous montrer le prix pour votre pays, l'Extension interroge ParityDeals (https://www.paritydeals.com/), qui déduit le pays à partir de votre connexion. ParityDeals ne reçoit rien de l'Extension en dehors de la requête elle-même.

InboxSDK (Intégration Gmail)

L'Extension utilise InboxSDK (https://www.inboxsdk.com/) pour s'intégrer à l'interface de Gmail : afficher la barre latérale et détecter les contacts de l'e-mail que vous ouvrez.

PostHog (Analytiques)

L'Extension utilise PostHog (https://posthog.com/) pour les statistiques d'utilisation. PostHog nous aide à comprendre comment l'extension est utilisée et à identifier les problèmes. Les données collectées incluent :

  • Identifiant d'installation (un code aléatoire). Si vous activez PLUS, il est associé à votre licence.
  • Événements d'utilisation des fonctionnalités (ex: "email enregistré", "enregistrement créé")
  • Rapports d'erreur pour le débogage, sans contenu d'e-mail (voir Rapports d'erreur ci-dessous)
  • Un indicateur booléen précisant si votre utilisateur Odoo a accès à plus d'une société (utilisé pour savoir si les fonctionnalités multi-sociétés sont pertinentes). La liste des sociétés et leurs noms ne sont PAS envoyés.

Politique de Confidentialité de PostHog: https://posthog.com/privacy

Désactiver: Vous pouvez désactiver les statistiques d'utilisation à tout moment dans Paramètres > Général (« Partager des données d'utilisation anonymes »). Ce réglage couvre la plupart des statistiques d'utilisation ; les rapports d'erreur (décrits ci-dessous) et quelques événements de service, comme un changement de plan, sont envoyés malgré tout.

Rapports d'erreur : Les rapports d'erreur sont envoyés quel que soit le réglage des statistiques, car ils décrivent l'état de l'application et non votre activité. Chaque rapport contient le message d'erreur et ses détails techniques, les versions de l'Extension et d'Odoo, et l'identifiant aléatoire d'installation — jamais le contenu des e-mails ni les identifiants de connexion. Si l'erreur provient de votre Odoo, le rapport inclut le message d'erreur d'Odoo, qui peut contenir l'adresse de votre instance. La base légale est notre intérêt légitime à détecter et corriger les défauts. Si vous avez ou avez eu PLUS, vous pouvez vous y opposer à tout moment en écrivant depuis l'adresse e-mail de votre licence à odoointegrations.team@gmail.com.

Partage de données avec des tiers

Nous NE vendons PAS vos données et ne les partageons pas à des fins publicitaires ou de courtage de données.

L'Extension et ses services communiquent avec :

  • Votre instance Odoo : L'Extension envoie des requêtes API à l'URL Odoo que vous configurez pour récupérer et créer des enregistrements
  • Polar: Uniquement pour la gestion des abonnements (e-mail, identifiant d'installation, statut d'abonnement, traitement des paiements)
  • PostHog: Statistiques d'utilisation et rapports d'erreur, sans contenu d'e-mail. La plupart des statistiques d'utilisation peuvent être désactivées dans Paramètres > Général (« Partager des données d'utilisation anonymes ») ; voir Désactiver.
  • ParityDeals : Uniquement pour vous montrer le prix pour votre pays
  • API Gmail (Google) : Uniquement si vous activez l'enregistrement automatique
  • Google Forms : Le questionnaire de désinstallation, uniquement si vous l'envoyez
  • GitHub : Avis internes sur les abonnements PLUS présentant des problèmes, sans e-mail ni nom

PostHog stocke les statistiques dans l'Union européenne (Francfort). D'autres, comme GitHub, peuvent traiter des données en dehors de celle-ci.

L'Extension NE fait PAS :

  • Vendre vos données à des courtiers de données
  • Partager des données à des fins publicitaires
  • Envoyer le contenu de vos e-mails ou vos fiches Odoo au développeur de l'extension

Politique d'utilisation des données des services API Google

L'utilisation et le transfert par Intégration Odoo pour Gmail des informations reçues des APIs Google sont conformes à Google API Services User Data Policy, y compris les exigences d'utilisation limitée.

Conformité à l'utilisation limitée :

  • L'Extension ne lit vos e-mails que lorsque (a) vous ouvrez un e-mail, (b) vous avez configuré les notifications Odoo (PLUS), pour lire les e-mails que votre Odoo vous envoie, ou (c) vous avez activé l'enregistrement automatique et lié un fil à une fiche Odoo (un consentement par fil)
  • Les données lues via l'API Gmail sont utilisées exclusivement pour l'objectif déclaré : enregistrer ces e-mails dans votre Odoo
  • Aucune donnée Gmail n'est utilisée pour diffuser des publicités
  • Les données Gmail lues via l'API Gmail ne sont envoyées qu'à votre propre instance Odoo
  • Les données Gmail ne sont pas utilisées pour déterminer la solvabilité ou à des fins de prêt
  • L'Extension ne demande que le scope OAuth gmail.readonly. Elle ne peut pas envoyer, modifier, archiver ni supprimer d'e-mails en votre nom

Explication des autorisations

L'Extension demande les autorisations Chrome suivantes :

Autorisations requises (Accordées à l'installation)

  • scripting: Nécessaire pour injecter l'interface de la barre latérale dans Gmail
  • storage: Nécessaire pour sauvegarder votre configuration Odoo et mettre en cache les réponses API dans le stockage de Chrome
  • host_permissions (mail.google.com): Nécessaire pour accéder à l'interface Gmail et afficher la barre latérale
  • host_permissions (*.odoo.com): Nécessaire pour communiquer avec les instances cloud Odoo Online (ex: votreentreprise.odoo.com) et, lorsque vous cliquez sur « Détecter Odoo automatiquement », pour lire les adresses de vos onglets odoo.com ouverts
  • host_permissions (api.polar.sh): Nécessaire pour la gestion des abonnements et le traitement des paiements
  • host_permissions (api.paritydeals.com): Nécessaire pour offrir des réductions de Parité de Pouvoir d'Achat (PPA) selon le pays de l'utilisateur

Autorisations optionnelles (Demandées si nécessaire)

L'Extension demande des autorisations optionnelles pour les instances Odoo auto-hébergées et pour l'enregistrement automatique :

  • optional_host_permissions (https://*/*): Utilisé UNIQUEMENT si vous vous connectez à une instance Odoo auto-hébergée sur un domaine personnalisé (ex. : odoo.votreentreprise.com ou erp.exemple.com), ou pour le domaine des API de Google (www.googleapis.com) lorsque vous connectez Gmail pour l'enregistrement automatique. Chaque adresse n'est demandée que lorsque vous en avez besoin.
  • identity: Utilisé UNIQUEMENT lorsque vous choisissez d'activer l'enregistrement automatique. Permet à l'Extension de terminer la procédure de connexion Google qui donne accès à l'API Gmail (scope gmail.readonly). Demandé lorsque vous activez l'enregistrement automatique ou cliquez sur « Connecter Gmail » dans Paramètres > Enregistrement des e-mails.
  • alarms: Utilisé UNIQUEMENT lorsque l'enregistrement automatique est actif. Permet à l'Extension de se réveiller périodiquement en arrière-plan pour vérifier s'il y a de nouveaux e-mails dans les fils que vous avez liés. Demandé lorsque vous activez l'enregistrement automatique ou cliquez sur « Connecter Gmail ».

Note : L'Extension ne supporte que les connexions HTTPS pour la sécurité. Les connexions HTTP ne sont pas autorisées.

Quand les autorisations optionnelles sont demandées

Chrome vous demandera d'accorder des autorisations optionnelles lorsque :

  • Vous configurez une URL Odoo personnalisée qui n'est pas un domaine *.odoo.com
  • Vous choisissez explicitement de vous connecter à une instance Odoo auto-hébergée
  • Vous connectez Gmail pour l'enregistrement automatique

Vous pouvez refuser ces autorisations si vous utilisez uniquement Odoo Online (*.odoo.com). L'Extension fonctionnera normalement avec Odoo Online sans accorder d'autorisations optionnelles, sauf l'enregistrement automatique.

Pourquoi ces autorisations optionnelles ?

De nombreuses organisations hébergent Odoo sur leurs propres serveurs avec des domaines personnalisés (ex: erp.acme.com, odoo.monentreprise.net). Pour supporter ces utilisateurs, l'Extension demande des autorisations optionnelles larges. Cependant :

  • Ces autorisations sont UNIQUEMENT utilisées pour communiquer avec VOTRE instance Odoo configurée et, avec l'enregistrement automatique, avec l'API Gmail de Google
  • Elles ne sont JAMAIS utilisées pour accéder à d'autres sites web
  • Vous pouvez les révoquer à tout moment dans les paramètres Chrome
  • L'Extension ne les demande que si vous saisissez une URL Odoo personnalisée ou connectez Gmail pour l'enregistrement automatique

Vos droits sur vos données

Vous avez les droits suivants concernant vos données :

  • Accès : Votre configuration est stockée dans votre navigateur et vos fiches dans votre Odoo, que vous contrôlez. Pour vos données d'utilisation, voir Suppression.
  • Suppression : Vous pouvez supprimer les données de l'Extension en :
    • Cliquant sur le bouton actualiser (efface le cache)
    • Supprimant l'Extension de Chrome (efface les données stockées dans ce navigateur)
    • Nous demandant de supprimer vos données d'utilisation : si vous avez ou avez eu PLUS, écrivez à odoointegrations.team@gmail.com depuis l'adresse e-mail de votre licence et nous supprimerons les données d'utilisation des installations liées à votre licence. Si vous n'avez jamais eu PLUS, vos données d'utilisation ne sont liées ni à votre nom ni à votre adresse e-mail ; nous ne pouvons les rechercher que si vous nous donnez l'adresse de votre Odoo et qu'un rapport d'erreur la contient.
  • Portabilité : Les fiches que vous créez et les e-mails que vous enregistrez restent dans votre Odoo, et vous pouvez les exporter avec les outils propres à Odoo
  • Contrôle : Vous pouvez arrêter l'Extension à tout moment en la supprimant. Si vous avez connecté Gmail, vous pouvez aussi révoquer son accès dans les autorisations de votre compte Google.

Conservation des données

L'Extension conserve les données comme suit :

  • Données de configuration : Stockées dans ce navigateur jusqu'à ce que vous supprimiez l'Extension
  • Réponses API en cache : Cessent d'être utilisées au bout de quelques minutes ; supprimées lorsque vous cliquez sur Actualiser ou vous connectez à un autre Odoo
  • Préférences utilisateur : Stockées dans ce navigateur jusqu'à ce que vous supprimiez l'Extension

Lorsque vous désinstallez l'Extension, Chrome supprime les données stockées dans ce navigateur. Si vous utilisez la synchronisation Chrome, l'adresse de votre Odoo, votre clé API et vos préférences peuvent rester dans votre compte Google.

Confidentialité des enfants

L'Extension n'est pas destinée aux enfants de moins de 13 ans. Nous ne collectons pas sciemment d'informations personnelles d'enfants de moins de 13 ans.

Modifications de cette politique de confidentialité

Nous pouvons mettre à jour cette politique de confidentialité de temps en temps. Nous informerons les utilisateurs de tout changement important en mettant à jour la date "Dernière mise à jour" en haut de cette politique et, si nécessaire, via les notifications de mise à jour de l'Extension.

L'utilisation continue de l'Extension après les modifications constitue l'acceptation de la politique de confidentialité mise à jour.
